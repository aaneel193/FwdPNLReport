Workspace guide

Slice on the left. Analyze on the right. The hierarchy is Activity Bucket → Region → AMA / NON-AMA → Strategy → Deal Type → Curve → Counterparty → Deal No.

Year2 headers expand to Year, then Contract Month. Parent rows already contain subtotals. The pinned grand total is calculated from filtered source records, not visible rows.

Snapshot dates are reporting dates; column periods are delivery periods. Preset exclusions are not configured. “Current only” / “Prior only” indicates row presence, not new-deal classification. A genuinely absent position contributes zero on that side; an unavailable snapshot cannot be selected.

Find row is navigation only and does not change totals. Selecting a row changes the focus path only. Select a financial cell or press Enter to inspect Current / Prior / Change. Ctrl-click then Shift-click selects a range without opening the inspector. Arrow keys navigate cells; Left/Right on a hierarchy label collapse/expand; Shift-select cells and Ctrl+C copies the range with headers.

Excel export contains all expanded matrix rows (not just the rendered viewport), with context and parent subtotal labels. Parent and child rows must not be summed together. Print/PDF prints the current expanded view.

Data is published locally, with no external scripts or data transmission. Rebuild the workspace to pick up a newly refreshed workbook. Files contain company data; keep them in authorized locations.
